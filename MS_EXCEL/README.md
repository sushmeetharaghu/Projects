# Excel Analytics Projects

This repository contains two Excel-based analytics projects: a quick-commerce order and customer analysis, and an e-commerce sales dashboard.

---

# Project 1: Quick-Commerce Order and Customer Analytics

## Description

**This quick-commerce analytics project provides valuable insights into order trends, delivery performance and customer value, and helps identify marketing strategies to improve retention and revenue.**

Using Microsoft Excel, this project analyzes 22,800+ orders placed by 3,750 customers between January and September 2021. It studies order distribution across delivery areas, time slots, weekdays/weekends and months, and tracks completion rates and delivery times (order-to-arrival, arrival-to-pickup, pickup-to-delivery). It also evaluates how discounts vary by delivery area and time slot, compares customers acquired from six sources (Organic, Google, Instagram, Facebook, Snapchat and Offline Campaigns), and calculates customer lifetime value (LTV) by acquisition source and acquisition month.

## Skills Used

*Data cleaning and preparation, Exploratory data analysis, Customer segmentation, Customer lifetime value (LTV) analysis, Data visualization, Report generation*

## Technologies and Features Used

**Microsoft Excel, Pivot Tables, Pivot Charts, Excel Tables, SUMIFS, COUNTIFS, MINIFS, CHOOSE**

## Project Structure

| Sheet | Purpose |
|---|---|
| Source data | Acquisition source for each user (3,750 users) |
| Transaction data | Order-level data (22,823 orders) with timestamps, delivery times, completion flag, ratings and amounts |
| Order level analysis | Order distribution by delivery area, slot and month, plus discount analysis |
| complete rate analysis | Completion rate by area, slot, weekday and month |
| delivery analysis | Average order-to-delivery time by area and month |
| customer level analysis | Source-wise revenue, completion rate and LTV by acquisition month |

## Key Insights

- The overall order completion rate is **99.55%** (only 102 cancelled orders out of 22,823).
- **Organic** is the largest order source, followed by Google, Offline Campaign and Instagram.
- About 70% of orders are placed on weekdays.

## Final Outcome

The final outcome of this project was a comprehensive insight report with pivot-based charts that outlines order and delivery trends in the dataset. This includes the overall completion rate, delivery-area and time-slot analysis, source-wise customer segmentation, customer lifetime value analysis, and recommendations for improving retention and marketing efficiency.

# Project 2: E-Commerce Sales Dashboard

## Description

**This e-commerce sales dashboard project provides a clear, interactive view of revenue, order value and marketing funnel performance across product categories and cities.**

Using Microsoft Excel, this project turns 9,700+ rows of raw sales data into a dashboard that tracks monthly revenue and average revenue per order, impressions and conversion rate (orders per impression), and the city-wise distribution of orders. It also summarizes total revenue and average revenue per day for each product category (Sports, Mobile, Books and TV) as of the latest sales date, so category performance can be compared at a glance.

## Skills Used

*Data cleaning and preparation, KPI calculation, Trend analysis, Data visualization, Dashboard design*

## Technologies and Features Used

**Microsoft Excel, Pivot Tables, Pivot Charts, Slicers, Excel Formulas, Conditional Formatting**

## Project Structure

| Sheet | Purpose |
|---|---|
| Raw Data | Daily sales data by category and city (impressions, carts, orders, average order value, revenue) |
| Revenue and ARO trend | Monthly revenue and average revenue per order |
| impressions and conversions | Monthly impressions and conversion rate |
| City wise distribution | Total orders by city |
| Calculation | Monthly aggregates, conversion rate, total and average revenue per category |
| Dashboard | Final dashboard with revenue, impressions and city-distribution charts and category KPIs |

## Final Outcome

The final outcome of this project was an interactive Excel dashboard that summarizes sales trends, marketing funnel performance and city-wise order distribution. It lets stakeholders compare category revenue, spot monthly trends in revenue and conversions, and identify the top-performing cities to support business decisions.
